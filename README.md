# Static Site Generator

**A lightweight static site generator built from scratch in Python that transforms Markdown files into beautiful, responsive HTML websites.**

---

## 📌 Description

This project demonstrates core web development concepts including file system operations, text parsing, HTML generation, and automated build processes.  
It provides a simple way to turn plain Markdown into clean, professional, and responsive HTML websites.

---

## ✨ Key Features

- 📝 Converts **Markdown content** to semantic HTML  
- 📱 Generates **responsive, mobile-friendly pages** with custom CSS  
- 📂 Supports **nested directory structures** for organized content  
- 🧭 Includes **automatic navigation generation**  
- 🎨 Implements a **clean, professional design system**  
- 📰 Handles both **individual pages** and **blog-style content**  

---

## ⚙️ Technical Highlights

- 🐍 Built with **vanilla Python**, using only standard library modules  
- 🔧 Implements **custom Markdown parsing logic**  
- 🌐 Generates **clean, semantic HTML5 markup**  
- 🔄 Uses **recursive file processing** for scalable content management  
- ♿ Demonstrates understanding of **web standards and accessibility principles**  

---

## 📖 Overview

This project showcases fundamental software engineering skills such as:  
- File I/O  
- String manipulation  
- Templating  
- Building tools that solve real-world problems  

The generator produces fast, **SEO-friendly static websites** that can be deployed anywhere without server-side dependencies.

## 🚀 Example Use Case

- Create a personal blog from Markdown notes  
- Build lightweight documentation sites  
- Generate fast, responsive landing pages without relying on heavy frameworks
